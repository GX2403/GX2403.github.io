自动改房号

⚠ 修改群名需要 bot 为群管理员
插件面板可单独关闭「改群名功能」，关闭后仍可记录房号但不改群名
本群 /silenton 开启后也不再实际改群名
发送房号无需 / 前缀；其它指令需以 / 开头
设置房号
单独发送五位数字房号

设置当前群房号。群名中若已有五位房号（可带后缀），则只替换该房号；否则改为「房号 ⎮ 原群名」。

示例：12345
五位数字 + 后缀

支持文字或表情后缀，写入群名时统一为表情：

发送群名中的房号
5361653616
53616龙　或　53616🐉53616🐉
53616虾　或　53616🦐53616🦐
53616撒　或　53616🍕53616🍕
相关指令
/清空房号

清空房号，群名改为「待开房 ⎮ 原群名」

/恢复群名

恢复为修改房号前缓存的原群名，并清空房号记录

⚠ 需曾成功改过群名以缓存原名

/auto

/停车

清空未来排表，群名改为「辛苦了」，房号进入停车状态（需先恢复后再设房号）

⚠ 需要插件管理员权限

画廊功能

⚠ 中文指令必须以 / 开头才会触发，避免误触聊天模型
指令与参数之间可无空格，如 /看所有mzk、/看瑞希x3
可引用他人图片或聊天记录（合并转发）后发送上传指令
图片墙单页尽量展示 ≥100 张；画廊 ≤200 张时通常一张图发完
英文管理指令使用 /gall … 形式
查看
/看所有

所有画廊总览墙。已隐藏的画廊不会出现在总览中。

/看所有画廊名

查看指定画廊的缩略图墙（PID 标注）。可无空格；图多时自动分页，单页尽量 ≥100 张。

示例：/看所有mzk　/看所有 mzk
/看画廊名

从指定画廊随机发送 1 张图。

示例：/看瑞希　/看 临风
/看画廊名xN

随机看 N 张图，合并为一条消息发送。不重复抽样；默认最多 5 张，超出提示上限。

示例：/看瑞希x3　/看临风x5
/看画廊名-N

查看该画廊倒数第 N 张图。

示例：/看mzk-1
/看 PID [PID…]

按图片 ID 直接查看一张或多张。

示例：/看 123　/看 123 456
上传 / 撤销
/上传画廊名

将本条消息中的图片，或引用消息 / 聊天记录里的图片，上传到指定画廊。

⚠ 画廊需为 edit 模式，或由管理员操作

示例：/上传mzk　/上传 瑞希
/上传画廊名 force

强制上传，跳过查重检测。

示例：/上传mzk force
/取消上传

撤销自己最近一次上传（有时限，默认若干小时内）。

/取消上传记录ID

管理员撤销指定上传记录及其对应图片。

示例：/取消上传12
/上传记录ID

查看某条上传记录详情（本人或管理员）。

示例：/上传记录12
画廊管理（管理员）
/gall open 名称

创建新画廊。

示例：/gall open mzk
/gall close 名称

删除画廊记录及本地图片文件。

⚠ 不可恢复，请谨慎使用

/gall mode 名称 [模式]

查看或设置画廊模式：edit（可上传）/ view（只读）/ off（关闭）。

示例：/gall mode mzk　/gall mode mzk view
/gall hide 名称

隐藏画廊：不在 /看所有 总览中显示，仍可用 /看名称 直接访问。

示例：/gall hide mzk　或　/隐藏画廊mzk
/gall show 名称

取消隐藏，重新出现在总览墙。

示例：/gall show mzk　或　/显示画廊mzk
/gall alias add 名称 别名

给画廊添加别名，可用别名查看与上传。

示例：/gall alias add mzk 瑞希
/gall alias del 名称 别名

删除画廊别名。

/gall reload 名称

扫描画廊目录，将新增本地图片入库（适合批量导入后刷新）。

示例：/gall reload mzk
/gall download 名称

将指定画廊打包为 ZIP 并发送。

/gall log PID

查询某张图片的上传日志。

示例：/gall log 123

点歌功能

⚠ 指令必须以 / 开头，例如 /点歌、/语音点歌；没有 / 的“点歌”不会触发。
自然语言不需要 /，但需要唤醒词，例如“瑞希，我想听 歌名”。
只有明确说“语音点歌 / 用语音放 / 发语音”才会走语音，普通文字里出现“语音”不会误触。
PJSK 版本优先展示，原版紧随其后；普通用户每日次数由面板设置，管理员不限次数。
基础点歌
/点歌 歌名

搜索网易云音乐，回复候选面板，再回复数字选择歌曲。

示例：/点歌 アイディスマイル
/点播 · /听歌 · /放歌 歌名

与 /点歌 相同，选择后默认发送网易云音乐卡片。

示例：/点播 夜に駆ける
瑞希，我想听 歌名

自然语言点歌，不需要 /，但需要唤醒词（默认：瑞希 / 瑞希酱 / mizuki）。

示例：瑞希，我想听 シャルル
瑞希 来一首 歌名

也可以使用“来一首 / 放一首 / 点歌”等自然说法，同样需要唤醒词。

示例：瑞希 来一首 千本桜
语音点歌
/语音点歌 歌名

选择歌曲后，把整首歌曲作为一条 QQ 语音发送，不拆分音频。

示例：/语音点歌 アイディスマイル
/语音播放 · /用语音放 歌名

语音点歌的别名；仍需以 / 开头。

示例：/语音播放 夜に駆ける
瑞希，用语音放 歌名

自然语言语音点歌，不需要 /，但必须带唤醒词并使用明确的“用语音放”说法。

示例：瑞希，用语音放 シャルル
瑞希，语音点歌 歌名

自然语言也可以说“语音点歌 / 语音播放 / 语音放 / 发语音”。

示例：瑞希，语音点歌 千本桜

语音发送失败时会自动改发音乐卡片，不会白扣次数。

选择与取消
1 · 选1 · 第一首

在点歌面板后回复数字选择；只有发起人能选，默认 120 秒内有效。

示例：1
取消 · 算了 · 不用了

放弃本次点歌，不会扣除次数。

示例：取消
PJSK 优先规则
PJSK 版本 → 原版 → 其他版本

如果网易云有 PJSK 版本，会优先显示组合完整版，其次原版，再其次是 Another Vocal / 翻唱等。

示例：PJSK·25时 → 原版 → PJSK·角色
额度与帮助
/增加额度 @用户 [次数]

管理员专用：为被 @ 的用户增加当天可用额度；次数省略时默认增加 1 次。

示例：/增加额度 @小明 3
/点歌额度

查看今日已点次数和剩余次数；管理员显示不限次数。

/点歌帮助

发送图片版指令帮助；图片发送失败时会自动退回文字版。

/网易云状态

管理员查看网易云账号登录、VIP 状态、今日点歌统计和语音设置。
