点歌功能

⚠ 指令必须以 / 开头，例如 /点歌、/语音点歌；没有 / 的“点歌”不会触发。

PJSK 版本优先展示，原版紧随其后；普通用户每日次数由面板设置，管理员不限次数。

实效算法（含特殊技能）

实效 = 队长技能 + 其余四张技能 / 5，其中每张卡的技能值要带卡组上下文计算：

类型算法
普通 / 条件 / 持续取该 SLv 的 activateEffectValue
团分（同团加成）除自身外每名同团成员 +X，五人同团再 +X。例：MMJ 的 #547（基础 100，每名 +10）在五张 MMJ 时 = 150
bfes 花前（吸取）基础 + min(floor(其他卡实效 × rate/100), max)；默认平均，可切最大 / 最小
bfes 花后（角色等级）基础 110%，角色等级每 2 级 +1%，最多 +50%（封顶 160%，100 级吃满）；0/1 级只有基础值。等级取 Suite 的 characterRank
bfes V 家（异组）按「不同组合数」加值
花前 / 花后怎么选

两者是两张技能表（skillId 与 specialTrainingSkillId）。花后的实际值高于花前「最小吸取」时用花后，否则用花前（按吸取策略）；出图时卡面会切换成对应的特训前 / 特训后，并标注「花后」。

S6（第六次技能）

协力 6 次触发，默认 S6 随机一人（按平均实效算）；写 270s6 则 S6 固定吃那个队友的实效。

PT 算法
实效 = 队长技能 + (其余四张技能之和)/5 rate自己 = base_score + fever×0.5 + (实效×Σskill_score_multi[0:5] + S6实效×skill_score_multi[5])/100 rate队友 = base_score + fever×0.5 + 队友实效×Σskill_score_multi/100 自己分数 = floor(rate自己 × 自己综合力 × 4 + 5×1.5%×(自己+4×队友综合力)) 队友分数 = floor(rate队友 × 队友综合力 × 4 + 同一 activeBonus) 基础PT = 110 + 自己分数/17000 + min(13, 4×队友分数/340000) PT = floor(基础PT × 歌曲event_rate/100 × (1+加成/100)) × 火倍率

加成 = 活动加成（+ WL 支援加成）；火倍率：1–5 火 = 5×N，6–10 火 = 27/29/31/33/35。

常见问题
支援加成怎么比游戏里高 / 低？

支援张数按 WL 回合（12/20/25），且不与前排重复；加成表优先 WL 分表。

箱活为什么没有支援？

箱活（普通活动）本来就没有支援卡组，只有前排加成。

为什么实效和单张卡的技能数值不一样？

实效是整队口径：队长技能 + 其余四张 / 5，再叠加团分 / 吸取 / 异组 / 角色等级。

指令发了没反应？

必须带 / 前缀或 @机器人；纯文本不会触发。回「上一条还在算」就等同一条出图再发。
