PJSK 冲榜排表提醒

⚠ 部分指令需要对应权限；插件管理员可用 /addadmin 添加
指令均需以 / 开头（房号除外），不依赖唤醒词
CN 对应一次后无需重复；填表时请使用与对应时相同的 CN
支持班前 10 分钟 / 下班前 2 分钟提醒；约 0 点推送今日排班图
房号支持后缀：龙/虾/撒 或 🐉/🦐/🍕（统一为表情写入群名）
插件面板可配置：群黑名单、改群名开关、排表开关、提醒开关
所有人可用
单独发送五位数字房号

设置当前群房号并自动修改群名。已有房号时只替换房号段；可带后缀如 53616龙 → 53616🐉

⚠ 需要 bot 为群管理员（改群名时）

示例：12345　53616龙　53616🐉
/清空房号

清空当前群房号，群名改为「待开房 ⎮ 原群名」

⚠ 需要 bot 为群管理员

/恢复群名

将群名恢复为修改房号前记录的原群名，并清空房号记录

⚠ 需要 bot 为群管理员；需曾成功改过群名以缓存原名

/查表

显示发送者在本群的未来排表图（高亮本人班次，多日合并为一条聊天记录）

/cn对应 CN

添加/覆盖自己的 CN 到数据库

示例：/cn对应 南宮語墨
/替换班表 月 日 时 CN1 CN2

替换/交换目标时间两名人员的排班（也可用 /dsb 或 /代上班）

示例：/替换班表 5 20 18 語墨 Akari
/list

查看本群未来所有排班图（不特别高亮某人）

/添加排表

进入个人填空模式：按提示发送时间段，自动填入空位。管理员可用完整参数直接覆盖添加。

添加示例：/添加排表 （等待 bot 提示后） 7 1 10 17 7 2 10 返场
/pjsk帮助

显示本帮助摘要（也可用 /排表帮助、/冲榜帮助）

/auto

⚠ 需要 bot 为群管理员

/停车

清空本群未来排表，群名改为「辛苦了」，房号进入停车状态（再设房号需先恢复）

⚠ 需要 bot 为群管理员

/silenton · /silentoff

画廊功能

⚠ 中文指令必须以 / 开头才会触发，避免误触聊天模型
指令与参数之间可无空格，如 /看所有mzk、/看瑞希x3
可引用他人图片或聊天记录（合并转发）后发送上传指令
图片墙单页尽量展示 ≥100 张；画廊 ≤200 张时通常一张图发完
英文管理指令使用 /gall … 形式
查看
/看所有

所有画廊总览墙。已隐藏的画廊不会出现在总览中。

/看所有画廊名

查看指定画廊的缩略图墙（PID 标注）。可无空格；图多时自动分页，单页尽量 ≥100 张。

示例：/看所有mzk　/看所有 mzk
/看画廊名

从指定画廊随机发送 1 张图。

示例：/看瑞希　/看 临风
/看画廊名xN

随机看 N 张图，合并为一条消息发送。不重复抽样；默认最多 5 张，超出提示上限。

示例：/看瑞希x3　/看临风x5
/看画廊名-N

查看该画廊倒数第 N 张图。

示例：/看mzk-1
/看 PID [PID…]

按图片 ID 直接查看一张或多张。

示例：/看 123　/看 123 456
上传 / 撤销
/上传画廊名

将本条消息中的图片，或引用消息 / 聊天记录里的图片，上传到指定画廊。

⚠ 画廊需为 edit 模式，或由管理员操作

示例：/上传mzk　/上传 瑞希
/上传画廊名 force

强制上传，跳过查重检测。

示例：/上传mzk force
/取消上传

撤销自己最近一次上传（有时限，默认若干小时内）。

/取消上传记录ID

管理员撤销指定上传记录及其对应图片。

示例：/取消上传12
/上传记录ID

查看某条上传记录详情（本人或管理员）。

示例：/上传记录12
画廊管理（管理员）
/gall open 名称

创建新画廊。

示例：/gall open mzk
/gall close 名称

删除画廊记录及本地图片文件。

⚠ 不可恢复，请谨慎使用

/gall mode 名称 [模式]

查看或设置画廊模式：edit（可上传）/ view（只读）/ off（关闭）。

示例：/gall mode mzk　/gall mode mzk view
/gall hide 名称

隐藏画廊：不在 /看所有 总览中显示，仍可用 /看名称 直接访问。

示例：/gall hide mzk　或　/隐藏画廊mzk
/gall show 名称

取消隐藏，重新出现在总览墙。

示例：/gall show mzk　或　/显示画廊mzk
/gall alias add 名称 别名

给画廊添加别名，可用别名查看与上传。

示例：/gall alias add mzk 瑞希
/gall alias del 名称 别名

删除画廊别名。

/gall reload 名称

扫描画廊目录，将新增本地图片入库（适合批量导入后刷新）。

示例：/gall reload mzk
/gall download 名称

将指定画廊打包为 ZIP 并发送。

/gall log PID

查询某张图片的上传日志。

示例：/gall log 123

PJSK 计算器

⚠ 指令均需以 / 开头，不依赖唤醒词（改了默认唤醒词也可直接使用）
羁绊默认每把 S 评级，火倍率规则与游戏一致
方括号中的参数可选；不填火数量默认 0 火；有火数量但无用火把数时默认全部用火
队长任务
/leader 当前队长次数 每日次数 目标章数

示例：/leader 39 60 3
/exp 当前队长次数 每日次数 游玩天数

计算游玩指定天数后能达到的等级

示例：/exp 39 60 31
EX队长任务

示例：/exleader 39 60 3
/exexp 当前EX队长次数 每日次数 游玩天数

示例：/exexp 39 60 31
